## Wave predictions

The same protocol was applied to the earlier 50-step checkpoint and both new checkpoints. For each of the five episodes, recorded observations at seconds **0, 3, 5, 7, 9, 11, and 13** supplied both camera images and robot state to the saved model. The saved output processor converted each predicted 100-action chunk back to action units. All 35 chunks per checkpoint were finite; target comparisons were clipped at episode ends.

The table summarizes the **20 observations at seconds 5, 7, 9, and 11**. These are training-set observations, not held-out data or a closed-loop simulation.

Plots of all 20 comparisons show repeated direction changes in the demonstrated targets and almost flat predictions for all three checkpoints. At 1,000 updates, the first predicted pan target varies only from **−21.82° to −19.98°** across these wave observations. The new checkpoints have not improved the wave sequence, despite falling training loss. The earlier 50-step result reproduced the previous diagnostic exactly to the reported precision, providing a comparison against the same protocol.

This establishes failure to reproduce the wave on the sampled training observations. It does not establish the precise cause or prove that additional updates alone will solve it. Further optimization, action-target alignment/normalization checks, and a controlled single-episode fitting experiment are possible next investigations; none was started as part of this 1,000-update request. **Keep physical wave evaluation on hold until the offline trajectory reproduces meaningful side-to-side motion.** The successful raise-arm checkpoint remains available separately; C6 wave acceptance remains open.

## Reproduce the offline check

Run from the repository root with the pinned LeLab environment. This script never opens a robot or a live camera:

```sh
train_root="$HOME/.cache/huggingface/lerobot/outputs/train"
wave_run="$train_root/act_local_wave-c6_20261018_150106_2026-10-18_15-37-57"
baseline_run="$train_root/act_local_wave-c6_20261018_150106_2026-10-18_15-07-09"
HF_HUB_OFFLINE=1 .cache/lelab/venv/bin/python scripts/check_act_wave.py \
  --checkpoint "$baseline_run/run/checkpoints/000050" \
  --checkpoint "$wave_run/run/checkpoints/000500" \
  --checkpoint "$wave_run/run/checkpoints/001000" \
  --dataset-root data/lelab/local/wave-c6_20261018_150106 \
  --repo-id local/wave-c6_20261018_150106 \
  --output .cache/wave-act-1000-comparison.json
```

The script checks dataset indices, task metadata, finite targets, checkpoint restoration, and prediction shape/values, then records per-sample pan trajectories and per-joint errors. Per-joint outputs include the gripper's 0–100 units, so only the shoulder-pan metrics above are labeled degrees. The protocol intentionally requires 30 fps and episodes longer than 13 seconds.

Local evidence remains outside Git: `.cache/wave-act-1000-comparison.json`, `.cache/wave-act-1000-comparison.log`, `.cache/wave-act-1000-comparison.png`, and `.cache/wave-act-1000-training-complete.png`. Training logs and metadata remain in the LeLab job directory. Dataset, checkpoint files, and camera images were not uploaded.
